红线说明触发阶段
不承诺收益 最高口头、书面、群里、私聊一律不许说「保证」「肯定赚」「稳赚」。统一口径：出单是结果不是承诺，我们承诺方法+资源+陪跑。S0 / S2

支付到账确认与交接触发
T+30min
详细动作
  • 确认学员支付成功（支付截图 + 订单号），订单进入已付状态

S1基础信息摸排：把底数摸清

时限 T+2h ~ T+24h责任 带教 PM
阶段目标：摸排是一切陪跑动作的地基。摸不清底数就分供应链、发品、压进度，全部会翻车。摸排的产出不只是信息，而是「学员定级 + 陪跑方案初稿」。
1.1
摸排问卷下发
T+4h
详细动作
  • 进入交付群 4 小时内下发摸排问卷（用表单，不长篇大论，20 题以内、5 分钟填完）
  • 表单必须带提交截图要求，作为执行意愿的第一份留痕
  • 问卷入口 + 填写示例（让学员知道填到什么颗粒度）
  • 私聊单独发一次链接（群内发了不代表看到）
学员通知点T+4h 群内 + 私聊：「问卷 5 分钟，填完我就能给你定陪跑计划了。T+24h 前提交，我好提前给你排电话。」
交付物 · 问卷提交记录（含提交时间戳）
合规 / 风险提示问卷只发群内 → 70% 不看群。必须群内 + 私聊双发，24h 未提交触发电话。

学员通知点「给你发了 3 个品（清单见文件）。先不用全上，选 1-2 个最顺手的先上，我带你走一遍。」
交付物 · 发品清单 + 选品理由说明
合规 / 风险提示⚠️ 一口气发 20 个品 → 学员懵了、选择困难、最后一个都没上。宁可少而精。
4.4
上架一对一教学
T+10d
详细动作
  • 手把手带做第一个品：标题怎么写、主图怎么选、详情怎么排、价格怎么定、发货怎么填
  • 零基础必须陪着他点一遍（可视频/语音），不能只发教程链接
  • 上架 6 要素逐个过：标题/主图/详情/价格/发货/分类标签
  • 教完让他自己上第二个，确认他真会了
学员通知点「今天带你上第一个品，我发个语音，你边听边操作，卡住随时问我。上完你再自己上一个。」
交付物 · 上架教学记录 + 第一个品上架截图
合规 / 风险提示只发教程不陪练 → 学员卡在半路不动手，第一次上架的挫败感会直接终结陪跑。
4.5
上架质量验收（逐品）
T+10d
详细动作
  • 逐品检查 6 要素，不合格打回重做（不是嘴上说）
  • 标题检查：关键词有没有、长度、有无违禁词
  • 主图检查：清晰度、有无水印、有无夸大
  • 违禁词必查：最、第一、国家级、治愈、纯天然等一律不写
学员通知点「第一个品通过，第二个主图有水印，我给你标出来了，重新换一张。」
交付物 · 上架验收记录（每品 6 要素勾选 + 修改前后对比）
合规 / 风险提示⚠️ 违禁词导致商品下架/扣分 → 学员信任崩塌。带教必须每次都查词，这是硬要求。
4.6
上架完成时限硬要求
T+10d（48 小时内完成首批）
详细动作
  • 首批上架 48 小时内必须完成，不能拖
  • 超时的当天电话催，问具体卡点（不会写标题 / 不知道选哪个品 / 没时间）
  • 把「上架完成」和时间节点绑定：上架完 → 下周开始流量和转化课程，节奏上给学员盼头
学员通知点「你的上架这周内要完成，卡住了直接找我，别自己憋着。上架完我们下周进下一阶段。」
交付物 · 首批上架完成记录（含时间戳）
合规 / 风险提示上架拖过一周 → 后面运营课全部延后，陪跑周期拉长，学员失去信心。
4.7
供应链使用规范宣导
T+10d
详细动作
  • 再次强调只用机构审核供应链，不得私自从 1688/抖音/拼多多进货（一旦出问题机构不担责）
  • 不得刷单、不得虚假交易、不得搬运他人图片（违规后果说明清楚）
  • 价格保护：按建议售价区间出货，不得恶意低价引流破坏价格体系
学员通知点「记住，货只从我们对接的供应链走，别自己从别的地方拿，出事我们帮不了你。」
交付物 · 规范确认记录
合规 / 风险提示⚠️ 学员偷偷上 1688 或刷单 → 平台处罚学员，但学员会怪到陪跑头上。提前把这条说透。

S5运营 SOP 标准：让学员自己跑

时限 T+14d ~ T+21d责任 带教 PM
阶段目标：从「我教他做」转为「他自己按标准跑」。本阶段考核指标：SOP 交付完整度 + 学员日动作执行率。
5.1
日常运营动作 SOP
T+14d
详细动作
  • 每日动作清单（可勾选版）：上新 X 件 / 擦亮 X 次 / 回复全部消息 / 浏览竞品 X 分钟 / 数据记录
  • 每周动作清单：数据复盘 / 价格测试 / 补货 / 标题优化
  • 动作要具体到数字，不说「多上架」，说「每天上架 2-3 件」
学员通知点「运营 SOP 给你了，每天照着清单做，做完打个勾。月底我们看勾了多少。」
交付物 · 《日动作 SOP 清单》（勾选版，学员可打印）
合规 / 风险提示SOP 太笼统 → 学员做两天就废。必须拆到可勾选颗粒度。
5.2
数据看板 SOP
T+14d
详细动作
  • 明确只看 4 个核心指标：曝光、浏览/点击、咨询、成交
  • 每天固定时间记录（建议晚 9 点），截图存
  • 周维度对比：这周曝光比上周涨了还是跌了
  • 异常处理规则：曝光 <30 → 检查标题/类目；曝光有但咨询 0 → 检查主图和价格
学员通知点「每天发我一下这 4 个数，我帮你看有没有问题。这是判断你有没有做对的方法，不用你自己瞎猜。」
交付物 · 《学员数据日报模板》+ 异常处理对照表
合规 / 风险提示⚠️ 只给数据不给判断标准 → 学员看到数据跌就慌、直接放弃。必须给「跌了怎么办」的规则。
5.3
合规避坑 SOP
T+14d
详细动作
  • 违禁词清单：最/第一/国家级/绝对化/医疗功效/纯天然…（列成表，学员上架前自查）
  • 行为红线：不刷单、不虚假发货、不诱导好评、不站外引流、不碰灰产
  • 账号安全：不频繁改标题/类目（触发降权）、不频繁切换登录设备
学员通知点「上架前把这张表过一遍，宁可少写词也别踩线。被封了重新养号很耽误事。」
交付物 · 《违禁词自查表》+《行为红线告知书》
合规 / 风险提示学员被封号 → 归因到陪跑。必须提前预防 + 明确「这是平台规则，不是我能改的」。
5.4
客服话术 SOP
T+14d
详细动作
  • 给询价/议价/催付/售后四类场景的标准话术
  • 议价底线要提前给（不轻易降价，降价伤账号权重）
  • 回复时效要求：咨询 10 分钟内必须回，闲鱼掉回复率权重
  • 话术要给示例，不是给原则
学员通知点「买家咨询 10 分钟内必须回，这条比你上架还重要，直接影响你的曝光。」
交付物 · 《四场景话术卡》（可直接照抄）
合规 / 风险提示回复慢 → 掉权重 → 学员完全不知道为什么自己不曝光。这条要反复强调。
5.5
发货与售后 SOP
T+14d
详细动作
  • 发货时效：24h 内发出（影响体验分和权重）
  • 售后话术：先处理再复盘，不推诿
  • 异常订单（破损/漏发/退货）：按供应链规则走，谁出运费写清楚
学员通知点「发货 24 小时内发出，这是硬指标。做不了 3 件以上就先别上那么多品。」
交付物 · 发货时效要求 + 售后流程说明
合规 / 风险提示学员发货慢被差评 → 影响整条链接。宁可少上，别超能力发货。
5.6
SOP 交付与每日提醒机制
T+14d
详细动作
  • SOP 整理成可复制粘贴的表格/清单发到群文件，方便学员反复用
  • 前两周每日提醒执行（发清单 + 问完成情况），之后改为每周抽查
  • 执行率记录：每周统计「SOP 完成度」，低于 50% 找原因
学员通知点「SOP 清单在群文件，每天做完打个勾发我，我给你看进度。」
交付物 · SOP 交付记录 + 执行率周统计
合规 / 风险提示⚠️ SOP 发了不管 → 学员不看。前两周必须每天盯，这是从「陪跑」到「能自己跑」的关键过渡期。

S6首单突破与结业验收

时限 T+21d ~ 结业责任 带教 PM
阶段目标：结业标准只有一条：学员独立出第一单。本阶段要做的不是「催」，而是把前置动作一项项验收通过，把压力从「结果」转移到「过程」。
6.1
出单前置四项验收
T+21d
详细动作
  • 严格按顺序验收，前一项不过不进入下一项：
    · 选品确认 ✅（选定品类 + 确认发品清单）
    · 上架完成 ✅（首批 ≥3 款，每款 6 要素合格）
    · 优化达标 ✅（标题/主图/价格至少各优化过一轮，有记录）
    · 首单 ✅（真实成交订单截图）
  • 每项验收留痕（截图 + 日期 + 带教签字）
  • 明确告诉学员：「四项里前三项我帮你确认过了，现在只差最后一步。」
学员通知点「你的前三项都过了，现在就是等第一单。我这边盯着你的数据，有动静第一时间告诉你。」
交付物 · 出单前置验收表（三项勾选 + 截图）
合规 / 风险提示⚠️ 前置动作没做扎实就催出单 → 学员出不了单反过来怪你。这是整个陪跑最容易翻车的地方，务必守住前置。
6.2
首单冲刺专项（7 天）
T+21d
详细动作
  • 7 天冲刺方案：明确每天做什么（改标题 / 换主图 / 降价试探 / 刷擦亮 / 回复加速）
  • 每天复盘数据：曝光涨没涨、咨询有没有、有没有卡在某一环
  • 按数据找卡点：曝光低 → 标题/标签/上架量；曝光有咨询无 → 主图/价格；咨询有成交无 → 话术/信任
学员通知点「我们开始 7 天冲刺，每天我给你一个具体动作，你做完发我看数据。这 7 天是决定能不能出单的关键。」
交付物 · 7 天冲刺计划表 + 每日数据记录
合规 / 风险提示冲刺期不要一直催（焦虑型学员越催越退）。每天给具体动作，不给压力。
6.3
未出单归因分析（超过 7 天未出单）
T+28d
详细动作
  • 四类归因，逐项排查：
    · 不想做——动作量不够/拖延 → 调整节奏，不加压
    · 不会做——方法没掌握 → 补对应课程 + 1v1 精讲
    · 做得慢——单个环节卡住 → 定位环节，专项突破
    · 做了没流量——方向/选品/账号问题 → 换品或换类，别死磕
  • 归因结论写成《未出单诊断单》，同步 PM 主管
  • 不甩锅：客观说「我们一起找原因」，不要说「你自己没做」
学员通知点「7 天还没出单，我们不躲，一起看看卡在哪。我看了你的数据，问题在【X】，接下来我们集中解决这个。」
交付物 · 《未出单诊断单》+ 改进方案
合规 / 风险提示⚠️ 未出单就默认「学员不行」→ 退款风险直线上升。先归因再定性，方法问题要认。
6.4
出单证据留存与结果确认
出单当日
详细动作
  • 出单当日让学员发订单截图（成交时间、商品、金额）——这是结业凭证
  • 发单庆祝：群内/私聊恭喜，公开表扬（正向激励很关键）
  • 引导复购：「出第一单只是开始，接下来学怎么稳定出单」
学员通知点「恭喜！第一单出了 🎉 这就是你自己的项目跑通了。截图发我存档，接下来我教你做第二单。」
交付物 · 订单截图 + 结业确认记录
合规 / 风险提示无截图无凭证 → 后续争议说不清。必须当天收集。
6.5
结业验收与持续运营 SOP
出单后 3 天内
详细动作
  • 完整结业验收表：知识掌握 / 选品定款 / 上架执行 / 首单突破 / 闭环跑通 / 运营能力（6 维度逐项确认）
  • 交付《持续运营 SOP》：出单后怎么维持、怎么提升、怎么避免违规
  • 遗留问题建事项：「矩阵扩店待启动」等 → 明确后续负责人和时间
  • 续费/升班型建议：出单只是第一单，指向更高阶目标
学员通知点「结业验收表我发你，6 项都过了。剩下的运营 SOP 你收好，后面按这个跑就能稳住。后续想做大随时找我。」
交付物 · 《结业验收表》（6 维度）+《持续运营 SOP》+ 遗留事项清单
合规 / 风险提示出单后就「结业不管了」→ 学员掉出单状态，负面口碑。出单后必须给持续运营 SOP。

话术库

S2 电话 + 日常跟进 · 点击复制
话术不是照背，是按学员类型调整语气。焦虑型慢一点、被质疑型给数据、高高在上型从基础做起。

【破冰开场】通话前 3 分钟，先让学员开口

「X 哥/姐，我是你的带教老师 XXX。今天不着急讲课，就是想先跟你聊聊——你之前是做什么工作的？这次是怎么了解到我们这个课的？」

要点：不给开放式压力，问具体经历；认真听并复述一次。

【心理按摩】把问题归因外化

「你别觉得是自己不行。闲鱼这两年流量池子在收紧，很多人卡住不是因为不努力，是方法没跟上平台变化。我带的学员里，第一单基本都落在第 7 到 20 天，中间卡一两周太正常了。」

要点：外部归因 + 正常化 + 给区间预期，不说「你努力就能行」。

【预期管理·收益】

「收益我没法给你打包票，因为结果取决于你投入多少。但我能承诺三件事：方法给到位、供应链资源接到位、每天有人盯你进度。你按节奏走，出单是必然结果，只是时间问题。」

⚠️ 红线：不说「保证」「肯定赚」。用「出单是结果，不是承诺」替代。

【预期管理·时间】

「第一单快的话一周，慢的话一个月。越早动手越早出单。如果超过一个月还没出单，我们一起找原因，不甩锅——是方法的问题我们补方法，是你的问题我们帮你卡点。」

⚠️ 不给「几天必出单」的具体承诺。

【预期管理·边界】

「还有一条我必须提前说清楚：我们教的是方法、资源和陪跑。账号是你自己的，货是你自己发的，我们不代持账号、不代运营、不保证收益。这条提前讲明白，是为了不让你后面有误会。」

⚠️ 红线：这三条必须口头讲 + 书面写，双保险。

【异议】「能不能保证出单？」

「我不能保证，但我可以给你看数据：我带的学员里，按节奏走的 90% 在一个月内出了第一单。我能保证的是方法和陪跑到位——你没做的地方我会天天盯着你。」

⚠️ 不许说「保证」「一定能」。学员录音是常态。

【异议】「别人都说赚很多」

「截图我可以发你。但每个人起点不一样，横向比没意义。我们只跟你的上周比——你这周曝光多少、出了几单，这个才是你的真实进度。」

要点：不贬低同行，把话题拉回学员自己的数据。

【异议】「能不能帮我代运营」

「账号不能代持，这是平台和合规的要求。但我可以给你做到：每天一个具体动作、出问题随时问、每一步都告诉你为什么这么做。做到极致，比代运营更有用——因为能力长在你身上。」

⚠️ 不代持账号、不给账号密码。这条没得商量。

【异议】「我先自己试试」

「完全可以，你随时回来找我们。SOP 我照样发你，不锁你。你试出来了告诉我，我把方案给你调优。」

要点：不锁死、不绑架，反而建立信任。

【掉队跟进】连续 3 天未打卡

「好几天没看到你打卡了，是最近忙，还是课程哪块卡住了？跟我说一声，我给你把节奏调一下，别硬扛。」

⚠️ 私聊，不群里 @，给面子。不催只问原因。

【未出单归因】超过 7 天没出单

「7 天还没出单，我们不躲，一起看看卡在哪。我看了你的数据，问题在【X】。接下来我们集中解决这一件事，其他先放一放。」

⚠️ 先归因再定性。客观说「我们一起找原因」，不说「你自己没做」。

【出单庆祝】出单当日

「恭喜！第一单出了 🎉 这一单是你自己跑通的，不是别人替你做的。截图发我存档。接下来说明你想做第二单了，我们按这个思路往下走。」

要点：正向公开表扬，指向下一个目标（第二单），给连续性。

【结尾】结业 + 长期维护

「结业快乐 🎉 这 30 天你把自己的项目跑通了。后面遇到问题随时找我，想做大也可以找我聊，不用客气。」

⚠️ 出单后先给价值，别急着推销升单，容易掉口碑。
