4 条贯穿全程的红线

红线说明阶段
不承诺收益 最高口头、书面一律不许说「保证」「肯定赚」「稳赚」。口径：出单是结果不是承诺，我们承诺方法+资源+陪跑。P1/P2
不代持账号 最高不接账号密码、不代运营、不代发货。全案代运营班型走单独书面授权。P2/P4
不碰灰产 最高仿牌、假货、刷单、虚假交易、站外引流、无货源搬运——涉及一律拒接。P2/P4
前置不放水 高视频结业、上架验收、SOP 执行率——该卡的必须卡住。放水了学员翻车反过来算陪跑的账。P3/P6
待拍板 3 件事：① 37 个视频清单谁来定稿、是否分批下发节奏可行？② 「每日 3 件事」的固定时间点定在几点？③ 出单前置验收（P6 6.1）由带教签字还是 PM 主管签字？

P1销售交接：收款 → 拉群 → 分配

时限 T+0 ~ T+2责任 销售 → 交付带教 PM
阶段目标：销售收款后拉群并挂单，交付侧按标准接收。群命名与挂单是责任划分的锚点，不在群里口头交接。
1.1
销售收款（企微）→ 确认到账
T+0
详细动作
  • 学员通过 IP 号/直播间进入，销售在企微确认收款，留存付款凭证截图
  • 企微内同步交付带教 PM：学员称呼、班型、金额、付款时间
  • 到账不得滞后于 2 小时，滞后则交付侧有权拒接
学员通知点—（销售内部动作，学员无感知）
交付物 · 付款凭证截图 + 企微同步记录
合规 / 风险提示销售收款后未及时通知交付侧，导致学员空等——2 小时未同步视为未交接。
1.2
销售拉群（销售负责建群）
T+0
详细动作
  • 由销售拉群（不是交付侧），保留前端信任延续
  • 群成员：学员 + 销售 + 交付带教 PM（助教内部对接，不进群）
  • 销售拉群后立即 @交付带教 PM，明确交接对象
学员通知点T+0 销售群内发：「@带教老师 这是 XX 同学，从现在起交付陪跑由老师负责带你，我先把他交接给老师。」
交付物 · 交付群 + 群内交接确认截图
合规 / 风险提示销售拉群后长期潜水、学员有问题先找销售 → 群公告明确「交付期问题统一找带教老师」。
1.3
群命名规范 + 挂单
T+0
详细动作
  • 群命名：班型-期次-学员称呼（例：启航班-2510-张三）
  • 挂单：在交付系统/表格挂单，状态置「已拉群待接收」
  • 挂单信息含：班型、付款时间、学员标签、销售对接人
学员通知点—
交付物 · 挂单记录（群名 + 状态 + 时间）
合规 / 风险提示群名不规范、挂单缺失 → 后续无法统计交付量与责任追溯。这一步是数据起点。
1.4
交付侧接单回执
T+2
详细动作
  • 带教 PM 在群内回执接手：「已接手 XX 的陪跑，@销售」
  • 同步内部：挂单状态改「已交接」
  • T+2 未回执 = 未交接，学员问题仍归销售
学员通知点T+2h 内 带教 PM 群内发自我介绍 + 接下来节奏预告：「我负责你这 30 天带跑，接下来三步：先电话摸底 → 给你配学习清单 → 手把手带你上第一批品。」
交付物 · 回执截图 + 挂单状态更新
合规 / 风险提示回执缺失 → 退款纠纷时责任无法划分。必须留痕。
1.5
销售已承诺事项书面化
T+2
详细动作
  • 把销售口头承诺逐条落到文字，区分「公司可承接 / 不承接」
  • 不承接项必须在群内书面澄清（保证出单、保收益、代持账号）
  • 带教 PM 接手时已看到清单，避免口径打架
学员通知点T+2h 内 群内发《口径确认》：「我们承诺给你的是【方法+资源+陪跑】，账号和货都归你自己，我们不代持、不保证收益。这一条提前说清楚，是为了后面不误会。」
交付物 · 承诺拆解表 + 群内澄清截图
合规 / 风险提示⚠️ 学员留证「销售承诺包出单」→ 必须在陪跑启动前书面澄清，这是唯一防线。

P2摸排建档：电话 + 问卷

时限 T+3h ~ T+1d责任 交付带教 PM
阶段目标：会议结论：摸排 = 1. 电话 2. 问卷，两件事在 T+3h 内启动，T+1d 内完成。摸排产出不是信息，是学员定级 + 陪跑方案。
2.1
电话预约（提前 2 小时）
T+3h
详细动作
  • T+3h 内完成预约，给 2 个时段让学员选：「今晚 8 点还是明天上午 10 点？」
  • 禁止「现在方便吗」式临时询问，学员会戒备
  • 通话前必看：销售交接信息 + 学员诉求 + 已承诺事项
学员通知点T+3h 私聊：「今晚 8 点或明天上午 10 点，20 分钟电话，我得先了解你的情况，才好给你排后面的计划。」
交付物 · 通话预约确认记录
合规 / 风险提示临时突袭 → 学员抵触，后续预期管理讲不进去。
2.2
电话沟通：摸底 + 心理按摩 + 预期管理
T+1d
详细动作
  • 前 5 分钟让学员讲：怎么了解到我们、之前做过什么、最担心什么
  • 肯定 + 归因外化：「你主动来学、已经在填问卷了，这一步很多人做不到」「卡住不是你不行，是方法没跟上平台变化」
  • 预期管理三件套：收益（不承诺，看投入）/ 时间（第一单通常 7-21 天）/ 边界（教方法+资源+陪跑，不代持账号、不保证收益）
  • 当场确认三件事：选品方向、每天动作量、本周里程碑
学员通知点通话当天发《沟通确认单》，请学员回复「已确认」。
交付物 · 通话纪要 + 学员承诺点
合规 / 风险提示⚠️ 红线：不承诺收益、不承诺时间。统一口径「出单是结果不是承诺，我们承诺方法+资源+陪跑」。
2.3
问卷下发与回收
T+3h 下发 / T+1d 回收
详细动作
  • T+3h 内群内 + 私聊双发问卷，5 分钟填完，不超过 20 题
  • 要求提交截图，作为执行意愿的第一份留痕
  • T+1d 未提交 → 直接电话催，不在群里 @（留面子）
学员通知点T+3h：「问卷 5 分钟，填完我就能给你定计划。明天之前发我，我好提前给你排电话。」
交付物 · 问卷提交记录（含时间戳 + 截图）
合规 / 风险提示只发群内 → 多数人不看群。必须双发。
2.4
关键信息截图核验
T+1d
详细动作
  • 要后台数据截图（曝光/浏览/想要/成交），不收截图按零基础处理
  • 问清：现有几个号、注册多久、什么品类、有无违规限流史
  • 不信口头信截图——学员常夸大「我原来做过」
学员通知点—
交付物 · 账号底数 + 后台数据截图
合规 / 风险提示有违规史账号直接推上架 → 必被限流。先排申诉/养号，节奏顺延。
2.5
分类定级（A/B/C）
T+1d
详细动作
  • A 级：账号健康 + 时间充足 + 目标合理 → 全流程带
  • B 级：时间碎片 / 基础弱 → 录播为主 + 关键节点 1v1
  • C 级：执行意愿低 / 预期离谱 / 资源不足 → 降配 + 明确退出条件
  • ⚠️ C 级学员要上报主管，退款风险最高的一类
学员通知点—
交付物 · 学员定级结论
合规 / 风险提示不定级直接开课 → 后面所有节奏都错位。定级必须在开课前。
2.6
陪跑方案初稿下发
T+1d
详细动作
  • 输出学员版陪跑方案：定位 + 视频学习路径 + 发品方向 + 里程碑时间点
  • 内部方案：日动作量、跟进节奏、风险点、导师安排
  • 方案过一遍内部再发学员，别把没定的发给人家
学员通知点T+1d 内 发《你的陪跑方案》+ 预告视频学习开始：「方案给你了，接下来先学视频清单，学完带你上第一批品。」
交付物 · 陪跑方案（学员版 + 内部版）
合规 / 风险提示方案不落纸 → 后续扯皮「你当时不是这么说的」。

P3视频学习：37 个视频统一清单

时限 T+1d ~ T+7d责任 交付带教 PM + 助教
阶段目标：会议结论：准备 37 个视频，全员统一学习清单，每个视频对标一个「可交付动作」，学完即触发上架。不学完不上架。
3.1
37 个视频统一清单下发
T+1d
详细动作
  • 按会议要求全员统一 37 个视频清单，不按人区分（避免额外维护成本）
  • 每个视频标注对标动作：看完要做出什么（如「第3课 → 写出3个标题」）
  • 分批下发（每周一批），不要一次甩 37 个
学员通知点T+1d：「视频清单 37 个我放群文件了，分 4 周，每周一批。每看完一个就做对应的动作，做不出来我给你补。」
交付物 · 37 个视频清单（含每周批次 + 对标动作）
合规 / 风险提示一次给满 37 个 → 完播率崩。必须分批。
3.2
每日打卡 + 每周作业
每日/每周
详细动作
  • 每天打卡（看完打一次），带教每天必须回复（哪怕只回「收到」）
  • 每周 1 个实操作业（写标题/写详情/选品对比），必须批改给具体反馈
  • 作业存档：这是 P4 上架、P6 出单的素材来源
学员通知点每晚固定提醒：「⏰ 今天打卡还差，看完回个 1 就行。」
每周截止前：「明晚 10 点交作业，我给你批。」
交付物 · 打卡记录 + 作业批改记录（含原稿与修改稿）
合规 / 风险提示带教不回复打卡 → 学员 3 天内停摆。回复成本极低、效果极高。
3.3
掉队预警与补课
每日
详细动作
  • 连续 3 天未打卡 → 私聊问原因（不群里 @）
  • 连续 5 天未响应 → 电话跟进，判断是否降配
  • 完播率低于 50% → 暂停推进上架，先补学习
学员通知点「好几天没看到你打卡了，是最近忙还是课程哪里卡住？跟我说一声，我给你调下节奏。」
交付物 · 学习进度看板 + 预警记录
合规 / 风险提示掉队不预警 → 拖到出单期才发现没学完，前面全白做。
3.4
固定答疑节点
每周
详细动作
  • 群内固定答疑时段（建议每晚 20:00-21:00）
  • 每天固定操作时间点：带教每天在固定时间跟进检查进度
  • 1v1 通道：B/C 级学员每周至少 1 次，A 级按需
学员通知点每周日发《本周复盘》：学完 X 节 / 作业 Y 份 / 下周动作 3 条。
交付物 · 答疑纪要 + 每周复盘记录
合规 / 风险提示答疑只在群内 → 学员不好意思问。留 1v1 通道。
3.5
视频结业闸门
T+7d
详细动作
  • 完播率 ≥80% 才放行进入 P4 发品
  • 不达标 → 补学后重测，不进 P4（硬闸门）
  • 通过后当天通知，并约上架教学时间
学员通知点「视频部分通过了，明天开始带你上第一批品，我把供应链和发品清单发你。」
交付物 · 结业确认（完播率截图）
合规 / 风险提示⚠️ 放水是最大雷：学员没学完就上架，自己瞎摸索出问题，反过来怪课程。闸门必须守住。

P4发品上架：单品标准化

时限 T+7d ~ T+14d责任 交付带教 PM + 供应链
阶段目标：会议结论：按发品、单品标准执行，首批控制在 3-5 款，48 小时内完成上架。
4.1
分类给供应链
T+7d
详细动作
  • 按学员情况分三类：新手类目（标准普通供应链，易上手）/ 优势类目（3C 配件、品牌鞋服等，需资金和甄别）/ 高门槛类目（鲸选数码3C等，不适合新手）
  • 强边界：不推 1688 / 抖音 / 拼多多 / 视频号货源，只推机构审核供应链
  • 同步供应链对接人：学员情况 + SKU 范围
学员通知点「根据你的情况给你匹配【XX 类目】供应链，特点是【XX】，和你说的【XX 需求】比较匹配。」（讲清楚为什么给你这个类，让学员觉得被认真分析过）
交付物 · 分类结论 + 供应链匹配单
合规 / 风险提示⚠️ 不看基础一律推高门槛品类 → 上架失败、退款、投诉。宁可保守不要激进。
4.2
开通权限 + 规则告知
T+7d
详细动作
  • 开通学员供应链账号权限（下单/查价/看库存）
  • 规则写给学员看，不是口头说：起订量、退换货、发货时效、结算方式
  • 禁止事项：不得对外宣称官方合作、不得改价乱发、不得跨区发货
学员通知点「你的供应链权限开通了，我拉你进对接群，里面有价格表和下单流程。有问题先问我，别自己乱下单。」
交付物 · 权限截图 + 规则告知留痕
合规 / 风险提示规则没提前说 → 出货/售后阶段纠纷。必须书面。
4.3
首批发品清单（3-5 款）
T+7d
详细动作
  • 首批 ≤5 款，控制 3-5 款，多了学员做不完也看不明白
  • 每款配套：成本价、建议售价、利润、主图素材、卖点文案
  • 说明为什么选这几款：客群匹配 / 易出单 / 竞争小 / 有利润
  • 试品逻辑：「先上这 3 款跑数据，哪个跑得好再追加」
学员通知点「给你发了 3 个品（清单见文件）。先不用全上，选 1-2 个最顺手的先上，我带你走一遍。」
交付物 · 发品清单 + 选品理由说明
合规 / 风险提示⚠️ 一次发 20 个品 → 学员懵了、选择困难、最后啥也没上。宁可少而精。
4.4
单品标准：6 要素 + 一对一带做
T+10d
详细动作
  • 手把手带做第一个品：标题 / 主图 / 详情 / 价格 / 发货 / 类目标签，六要素逐个过
  • 零基础必须陪着他点一遍（可视频/语音），不能只发教程链接
  • 教完让他自己上第二个，确认真会了
  • 违禁词必查：最/第一/国家级/治愈/纯天然一律不写
学员通知点「今天带你上第一个品，我发语音你边听边做，卡住随时问。上完你自己再上一个。」
交付物 · 上架教学记录 + 单品 6 要素验收（修改前后对比）
合规 / 风险提示只发教程不陪练 → 卡在半路不动手，第一次上架的挫败感会终结陪跑。
4.5
48 小时内完成首批上架
T+10d
详细动作
  • 首批上架 48 小时内必须完成，不能拖
  • 超时当天电话催，问具体卡点（不会写标题 / 不知选哪个品 / 没时间）
  • 上架完 → 进 P5 每日 3 件事，节奏上给学员盼头
学员通知点「这周内要完成首批上架，卡住了直接找我，别自己憋着。上架完我们进每日打卡节奏。」
交付物 · 首批上架完成记录（含时间戳）
合规 / 风险提示上架拖过一周 → 后续全部顺延，陪跑周期拉长，学员失去信心。

P5每日 3 件事：节奏固化

时限 T+14d ~ T+21d责任 交付带教 PM
阶段目标：会议结论：每天固定 3 件事 + 固定时间节点，把陪跑从「被动等学员问」变成「固定节拍」。核心是让学员每天知道该干什么。
5.1
每日 3 件事（标准动作）
每日
详细动作
  • ①上新/维护商品：每天上架或优化 2-3 件（标题/主图/价格轮换）
  • ②回复与跟进：所有咨询 10 分钟内必须回（直接掉权重）
  • ③数据记录：晚间固定时间记录曝光/浏览/想要/咨询/成交 5 个数
  • 动作要具体到数字，不说「多上架」，说「每天 2-3 件」
学员通知点每天固定时间发今日 3 件事：「今天三件事：上 2 件新 / 把消息回完 / 晚上把数据发我。」
交付物 · 《每日 3 件事清单》（勾选版）
合规 / 风险提示SOP 笼统 → 学员做两天就废。必须拆到可勾选颗粒度。
5.2
固定时间节点跟进
每日
详细动作
  • 每天固定时间跟进（建议晚 9 点），不找学员，学员等你
  • 每天有进度记录：完成/未完成都要记，未完成的问一句卡在哪
  • 连续 2 天未完成 → 当天私聊跟进
学员通知点「今天三件事做完了吗？做完发我，我帮你看数据。」
交付物 · 每日跟进记录表
合规 / 风险提示不定固定时间 → 学员拖、你也忘，最后没人跟。节拍必须固定。
5.3
数据反馈与引导
每日/每周
详细动作
  • 每天回传数据 → 带教当天给判断和下一步动作
  • 异常给规则：曝光<30 查标题/类目；有曝光无咨询 查主图/价格；有咨询无成交 查话术/信任
  • 每周做一次对比：这周 vs 上周
学员通知点「数据我看了，曝光够但没人点——主图换个带场景的试试，明天发我看。」
交付物 · 数据日报 + 异常处理对照表
合规 / 风险提示⚠️ 只给数据不给判断 → 学员看到跌就慌、直接放弃。必须给「跌了怎么办」。
5.4
1v1 沟通 + 日常问候
每周
详细动作
  • 每周至少 1 次 1v1 沟通（不是等学员问，是主动约）
  • 日常问候：不只是有事才联系，群里/私聊有日常互动
  • 1v1 时机：上架后、出单冲刺前、掉队时、结业前
学员通知点「这周约你 15 分钟，看看你的数据，一起找找还能提效的地方。」
交付物 · 1v1 沟通记录 + 日常问候记录
合规 / 风险提示只在有事时联系 → 学员觉得「用完就走」。日常问候是黏性成本最低的手段。
5.5
群内答疑（双周节奏）
双周
详细动作
  • 群内固定答疑：把共性问题集中讲（双周一次）
  • 问题分类：选品问题 / 上架问题 / 流量问题 / 售后问题
  • 高频问题沉淀成 FAQ，后续直接甩文档
学员通知点答疑前发预告：「本周四晚上集中答疑，把你的问题提前发群里，我一起讲。」
交付物 · 答疑纪要 + FAQ 文档
合规 / 风险提示答疑无沉淀 → 同一个问题反复回答。每次答疑都要沉淀。
5.6
运营 SOP 标准下发
T+14d
详细动作
  • 下发运营 SOP：日动作清单 + 数据看板 + 合规避坑 + 客服话术 + 发货售后
  • 违禁词清单给学员自查（最/第一/国家级/纯天然…）
  • 前两周每日盯执行，之后改每周抽查
学员通知点「SOP 清单在群文件，每天做完打个勾发我，我给你看进度。」
交付物 · 运营 SOP + 执行率周统计
合规 / 风险提示SOP 发了不管 → 学员不看。前两周必须每天盯。

P6出单收口与结业

时限 T+21d ~ 结业责任 交付带教 PM
阶段目标：会议结论：逼单收口 + 出单核对 + 复盘引导。结业只有一条：学员独立出第一单。
6.1
出单前置三项验收
T+21d
详细动作
  • 严格按顺序，前一项不过不进入下一项：
    · 选品确认 ✅
    · 上架完成 ✅（≥3 款，6 要素合格）
    · 优化达标 ✅（标题/主图/价格至少各优化一轮，有记录）
  • 每项留痕（截图 + 日期 + 签字）
学员通知点「你的前三项都过了，现在就等第一单。我盯着你数据，有动静第一时间告诉你。」
交付物 · 出单前置验收表
合规 / 风险提示⚠️ 前置没扎实就催出单 → 出不来反怪你。这是最容易翻车的地方。
6.2
逼单收口 + 出单核对
T+21d
详细动作
  • 逼单收口：出单冲刺期主动推，不等学员自己着急
  • 出单核对：出单当日收订单截图（成交时间/商品/金额）——这是结业凭证
  • 确认是真实成交，非刷单；确认是学员自操作
学员通知点冲刺期每天给一个具体动作 + 复盘数据，给动作不给压力。
出单后：「恭喜第一单！截图发我存档，这是结业凭证。」
交付物 · 订单截图 + 出单确认记录
合规 / 风险提示无截图无凭证 → 后续争议说不清。当天必须收。
6.3
未出单归因（超 7 天）
T+28d
详细动作
  • 四类归因逐项排查：不想做 / 不会做 / 做得慢 / 做了没流量
  • 归因结论写成《未出单诊断单》，同步主管
  • 不甩锅：客观说「我们一起找原因」
学员通知点「7 天还没出单，我们不躲，一起看卡在哪。我看你数据，问题在【X】，接下来集中解决这个。」
交付物 · 未出单诊断单 + 改进方案
合规 / 风险提示⚠️ 默认「学员不行」→ 退款风险直线上升。先归因再定性。
6.4
结业验收 + 复盘引导
出单后 3 天内
详细动作
  • 结业验收表：知识掌握/选品定款/上架执行/首单突破/闭环跑通/运营能力（6 维度）
  • 交付持续运营 SOP：出单后怎么维持、怎么提升、怎么避免违规
  • 复盘引导语：话术卡 + 话术复盘到群里（会议结论）
学员通知点「结业快乐 🎉 后面有问题随时找我，想做大也可以找我聊。」
交付物 · 结业验收表 + 持续运营 SOP
合规 / 风险提示出单后就结业不管 → 学员掉出单状态，负面口碑。出单后必须给持续运营 SOP。
6.5
跨团队反馈 + 遗留跟进
结业后 3 天内
详细动作
  • 反馈获客：哪些话术易引发退款 / 哪些承诺需提前澄清
  • 反馈内容：哪几节课反馈差、哪些内容要补
  • 遗留问题建事项：「矩阵扩店待启动」等明确负责人和时间
学员通知点—
交付物 · 跨团队反馈记录 + 遗留事项清单
合规 / 风险提示反馈不回前端 → 前端继续用同样话术继续埋雷。闭环必须做。

每日汇报机制

会议结论：每天固定 3 件事 + 后台给对应下发指令
这是 P5 的核心。把陪跑从被动等问，固化成每天固定节拍——学员知道要干什么，带教知道要盯什么。
环节标准动作说明执行要求
① 上新/维护上架或优化 2-3 件标题/主图/价格轮换晚上发完成截图
② 回复跟进所有咨询 10 分钟内回超时会掉权重未回咨询当天补
③ 数据记录记录曝光/浏览/想要/咨询/成交5 个数，缺一不可晚 9 点前发带教
带教跟进当天回数据 + 给下一步动作固定时间，不找学员异常给处理规则
1v1 沟通每周至少 1 次不等学员问，主动约出单前/掉队时重点谈
群内答疑双周一次集中讲问题分类沉淀 FAQ提前预告时间
落地要点：固定时间跟进是关键——不找学员，学员等你。带教每天回数据 + 给下一步动作，学员才有持续感。

话术库

点击复制 · 可编辑

【逼单收口】出单冲刺期推着走

「今天这三件事做完了吗？数据发我看下。我们现在差的就是第一单，把它跑通了后面都是复利。」

要点：主动推、不等学员。给具体动作不给压力。

【出单核对】出单当日

「恭喜第一单！🎉 截图发我存档一下，这是结业凭证。后面想稳住或者做第二单，随时找我。」

要点：当天收截图，指向第二单。

【预期管理·收益】

「收益我没法打包票，取决于你投入多少。但我承诺三件事：方法给到位、供应链资源接到位、每天有人盯你进度。你按节奏走，出单是结果。」

⚠️ 红线：不说「保证」「肯定赚」。

【预期管理·时间】

「第一单快的话一周，慢的话一个月。越早动手越早出单。超一个月没出单，我们一起找原因，不甩锅。」

⚠️ 不给「几天必出单」承诺。

【预期管理·边界】

「有一条提前说清：我们教方法、资源和陪跑。账号是你自己的、货是你自己发的，我们不代持账号、不代运营、不保证收益。」

⚠️ 口头讲 + 书面写，双保险。

【每日3件事】固定推送

「今天三件事：上 2 件新 / 把消息全回完 / 晚上把数据发我。做完打个勾，我帮你看下一步。」

要点：固定时间发，学员形成节拍。

【掉队跟进】连续3天未打卡

「好几天没看到你打卡了，是最近忙还是课程哪块卡住？跟我说一声，我给你把节奏调一下。」

⚠️ 私聊不给面子，不催只问原因。

【未出单归因】超7天没出单

「7天还没出单，我们不躲，一起看卡在哪。我看你数据，问题在【X】。接下来集中解决这一件。」

⚠️ 先归因再定性，不说「你没做」。

【异议】「能保证出单吗」

「不能保证。但按节奏走的学员大部分一个月内出了第一单。我能保证的是方法和陪跑到位，你没做的地方我天天盯。」

⚠️ 不许说「保证」「一定能」。

【1v1日常问候】非有事时

「最近怎么样？上架顺不顺？有没有卡住的随时说，别自己憋着。」

要点：日常问候是黏性成本最低的手段。

【结业】出单后

「结业快乐 🎉 30天你把自己的项目跑通了。后面有问题随时找我，想做大也可以找我聊。」

⚠️ 先给价值，后谈升级，别急着推销。
