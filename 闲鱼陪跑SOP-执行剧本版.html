群成员备注名标准

T+2h 建群后
触发：建群、相关人员（销售已拉入）进群后，第一时间把每个相关人都备注成「角色@花名」，便于全程追溯与交接。
标准：统一格式「角色@花名」，全员一致；后续任何沟通/交接/复盘都能一句话定位责任人。
红线：备注名必须真实可溯源，不写昵称/表情代称；商务花名空缺时先 @运营主管 补齐再开服务。

接单启动

T+0 ~ T+3h
触发：销售支付成功并拉群，群内 @你 + @范志强（运营主管）。你从"被拉进群"到"正式接管群"。
🔴 群名必须统一（强制标准） 格式：学员姓名 + 课程类型# + 日期 + 你的花名 江涛598正价#20261016@墨峭 课程类型三选一：598正价 / 98体验 / 7天免费

欢迎语（复制后改花名/链接）

@全体成员 同学你好，我是你的专属运营教练【墨峭】👋 接下来由我全程陪你跑通闲鱼，从注册账号到出第一单，一步一步带你走。 👥 群内分工 · 日常运营 / 收款 → 找我 @墨峭 · 订单后问题 → 找 @子萍（订单专员） · 想升级资源 / 广告投放 → 找对应商务 📚 带教流程（跟着节奏走就行） 1. 先按要求把账号注册好、实名、基础设置做完 2. 看完群文件里《闲鱼开店基础》《文字版秘籍》打底 3. 新号养号几天，模拟真实买家刷一刷 4. 每天固定发品 5 个，发完把后台截图发群里 @我 5. 出单后客服、发货、售后我带你处理 🕐 我的服务时间：每天 9:30–23:00，急事直接 @我 📦 每天固定动作：发品 5 个，发完截图发群里 @我。咱们按节奏一步步来，先跑通再放大 💪 💬 跟你说句心里话：我对你提要求，是因为这套流程跑通过，照着走更容易出结果。哪一步卡住、跟不上，你直接说卡在哪，我们一起拆小、放慢，不会因为你进度慢就不管你。你只要跟着动手、有问题及时问，别自己闷着卡住就行。 🧰 服务范围：账号注册指导、起号养号、选品铺货、标题主图详情、客服话术、发货和常见纠纷处理。
交接：本阶段你在"接"，销售在"交"。无需你再交接他人。
红线：欢迎语不承诺"包出单/保收益"，只讲方法+节奏+陪跑；款项一律走企业微信，不私收。

摸排建档

T+6h
触发：接管群后立刻做初步调研，把学员底数和账号资产摸清楚。重点做预期管理：3 个号是更优方案，但 1 个也能起步，不强求。

调研问卷（复制发群）

【开店摸底】同学直接回复即可： 1. 真实姓名： 2. 手机号： 3. 目前有几个闲鱼店铺？店名分别是： 4. 之前做过闲鱼吗？大概月销多少： 5. 每天能拿出多少时间运营： （账号数量不强求，1 个账号也可以起步，有几个填几个） ⚠️ 平台规则：1 个手机号 + 1 个支付宝对应 1 个实名店铺。 我们优先准备 3 个店铺账号（3 支付宝 + 3 手机号），尽量 1 天内准备好；条件有限 1 个也能起步。

预期管理 FAQ（学员常问，直接复制答）

Q：我只有 1 个手机号，只能弄 1 个账号行不行？ A：完全可以。单账号能正常上架运营、出单，只是风险集中（一旦限流就没备选）。先把这一个号做好，后续有多余手机号/支付宝再增加，我一样带你。 Q：是不是必须 3 个号，不够就不带？ A：不是！1 个账号也能正常跟着做。3 个号是更稳妥的方案（分散限流/违规风险、可测不同品类、容错更高），不是门槛。条件有限就先用 1 个号起步。
交接：摸排结果同步运营主管备案；账号异常须提前标注，避免后期掉链子。
红线：账号须本人实名合规，不代持、不碰灰产/侵权/无货源违规；账号异常必须留痕。
3

每日发品陪跑

T+1d 起 · 每天
触发：每日 10:30 之前。这是陪跑的"日常引擎"，发品是硬动作，不能断。

每日发品指令（复制发群）

☀️ 今日发品任务（每天 10:30 前） 给你 5 个商品素材（见群文件）：① 标题 ② 主图 ③ 详情文案 动作：上架后把【闲鱼后台截图】发群里 @墨峭 今天目标：5 件全上架 ✅ 卡住随时 @我
⏰ Day5 数据闸口（关键决策点）：若到第 5 天，学员仍「持续未发品 / 上架不达标 / 毫无出单迹象 / 零互动」，立即：① 运营教练整理数据截图 → ② 汇报运营主管（范志强）+ 陪跑商务 → ③ 三方决策下一步：补课时长 / 转班型 / 商务介入升单 or 退款风险预警。别让"没迹象"拖到第 2 周才暴露。
红线：每日发品不溶于水；商品素材须过合规审核（无侵权/违规词）；"出第一单"是学员自操作结果，不替学员承诺确定性收益。

成单闭环 + 升单

每次成单
触发：学员成单截图发群。你负责把"散单"收成"标准成单信息"、推进发货，并第一时间同步商务升单踢单。

成单信息表（复制让学员填，渔货栈必填渔货号）

【成单信息】学员成单后按此填： 产品： 渔货号：xxxx（渔货栈供应链必填） 收货人： 手机号码： 地址信息： 备注：（如颜色 / 发货拍视频） 成本价： 所属供应链： 学员姓名： 学员店铺名称： 专属运营教练：

收款确认话术（复制发群）

✅ 已收到学员转账（企业微信）【金额 / 产品】 @子萍 可以安排发货啦～ 订单信息见上 ⬆️

升单同步话术（复制发商务/主管）

📈 升单同步（发陪跑商务 + 运营主管） 学员【姓名】今日首单达成 ✅ 产品【xxx】 运营教练：@墨峭 数据：上架 X 件 / 出单 1 单 下一步建议：启动升单（复购供应链 / 扩店矩阵 / 高阶陪跑），请商务跟进踢单。
交接：成单信息 → 订单专员（子萍）备货发货；升单线索 → 陪跑商务。
红线：信息缺一不发货；先收款后发货；退款/纠纷按平台规则，留存沟通凭证与责任界定。
