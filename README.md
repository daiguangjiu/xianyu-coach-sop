# 闲鱼运营陪跑 SOP（执行剧本版）

本仓库沉淀「闲鱼学员陪跑」的标准作业流程（SOP），以**可执行、能带入角色**为设计目标：建群 → 接管 → 摸排建档 → 每日发品陪跑 → 成单升单 → 复盘结营，全流程角色、动作、话术、红线一目了然。

## 文件说明
- `闲鱼陪跑SOP-执行剧本版.html` —— **当前主版本（执行剧本版）**：含陪跑全流程一览图、角色地图、6 阶段执行剧本、话术工具箱；支持勾选进度、就地编辑、导出离线 HTML。
- `index.html` —— V2 版（6 阶段 / 32 项），演进记录。
- `闲鱼陪跑SOP-轻量时间轴版.html` —— 轻量时间轴初版（已被执行剧本版取代，保留）。
- `轻量时间轴版_归档.html` / `V1_归档.html` —— 历史归档。
